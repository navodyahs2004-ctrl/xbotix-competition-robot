# Xbotix Competition Robot

Autonomous robot project developed for the Xbotix competition using Python, Raspberry Pi, Arduino communication, and computer vision.

## Features
- Task-based robot control
- Object detection model integration
- Arduino serial communication
- Multiple task modules
- 4 out of 5 competition tasks completed

## Files
- `main.py` - main program
- `Task_1.py` - task 1
- `Task_2.py` - task 2
- `Task_3.py` - task 3
- `Task_4.py` - task 4

## Status
Completed 4 out of 5 tasks.
