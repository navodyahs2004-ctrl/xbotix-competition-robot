# Xbotix Competition Robot

This project is an autonomous competition robot developed for the Xbotix competition. It was built to perform competition tasks using Python-based control logic, Raspberry Pi, Arduino communication, and computer vision. The robot was developed to solve real task-based challenges in the competition environment, and this repository contains the main code, task modules, and project structure used in the implementation.

## Features
- Task-based robot control
- Object detection model integration
- Arduino serial communication
- Multiple task modules
- 4 out of 5 competition tasks completed

## Files
- `main.py` - main program
- `Task_1.py` - task 1
- `Task_2.py` - task 2
- `Task_3.py` - task 3
- `Task_4.py` - task 4

## What this robot does
This robot is a task-based autonomous robot designed for the Xbotix competition. It uses programmed task logic, sensor/camera-based detection, and controller communication to complete multiple competition tasks.

## Why this robot was built
This robot was built as a competition project to solve real-world robotic tasks under competition conditions. The goal was to design and implement a working autonomous system that could complete the required challenges efficiently.

## Current progress
This repository includes the implementation for 4 out of 5 competition tasks.
